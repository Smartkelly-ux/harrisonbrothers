# Harrison Brothers Plumbing

A static React website built with Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

The production site is written to `dist/`. Upload the contents of that folder to any static web host. Asset paths are relative, so the site can be hosted from a domain root or a subdirectory. No API keys or server runtime are required to build or serve the site.

The service request form currently displays a local confirmation only; connect it to a form provider or backend to receive submissions.

## Checks

```sh
npm run lint
```
